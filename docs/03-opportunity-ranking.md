# 3. Opportunity ranking: what to build first

Each candidate is scored 1–5 (5 = best) on six criteria that predict a fast, low-risk first sale for a solo builder using the logic-first playbook.

| Criterion | Question |
|---|---|
| **Urgency** | Is the pain triggered by an external event or deadline? |
| **Willingness to pay** | Does the buyer already pay a professional for this? |
| **Logic fit** | Is the core output a number or verdict computable from rules (no AI needed)? |
| **Competition** (inverse) | 5 = nobody sells a self-serve SMB version. |
| **Liability** (inverse) | 5 = a wrong answer has small consequences; 1 = serious harm or licensing issues. |
| **Build speed** | 5 = MVP in 1–2 days. |

## Recommendation

1. **Build CUSMAcheck now.** It has the highest score, it is already specified, and the August 2026 Section 338 tariffs make it *more* valuable. "CUSMA qualifies, but you still owe 50%" is exactly the confusion SMEs can't resolve alone. The low liability score is handled with disclaimers, the audit log, an expert-review route for autos and apparel, and errors-and-omissions insurance.
2. **Bolt on the Surtax Remission Finder** as CUSMAcheck's second module. It has the same buyer, the same HS-code data and the same Stripe account, and it turns the product into "both sides of the border".
3. **Bill 96 Site Audit as product #2.** It is a different buyer (any business selling into Quebec), and it is the one opportunity where a browser extension makes sense (a free "scan this page" lead magnet).
4. **Sales-Tax Registration Checker as a weekend free tool** to build traffic and capture emails, later a Shopify app.

## Why not the others (yet)

- **Mortgage triage:** urgent and logic-friendly, but consumers pay little. Referral revenue can require provincial mortgage-brokerage licensing.
- **Immigration, fintech:** licensing and capital requirements, and a wrong answer harms a person, not just a shipment.
- **Province Rules Checker:** valuable, but the rule base (10 provinces × many statutes) takes weeks to build and maintain. Revisit once there is revenue.

## The common thread

All top picks are **document-in, verdict-out web tools**. That is why the format is a **web app, not a Chrome extension**: there is no third-party page the user is already looking at. The exception is a Bill 96 "scan this page" extension as a marketing hook.
